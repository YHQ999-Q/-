# 系统局限（诚实版）对照 RSI 三类失败模式
① 探索不够针对 经验主要依赖 VibeCoding / OCR / ASR 的输入质量；系统不能自己生成学习经验，识别失效时只能靠人工补录（来源标记 human_input）。
② 验证不完备 已有前置校验：格式 + 多模态交叉置信度 + 语义自洽 + 边缘样本 Critic 复核，低置信度只留日志；但校验与主系统共用同一个大模型，仍有自确认风险，独立 Verifier 是未来工作。
③ 记忆合并不可靠 冲突检测不自动消解（显式修正语境也只做标记），两条都保留、等人确认；合并权重仍是预设规则，更高级的融合策略是未来工作。演示可用快照回滚兜底。
