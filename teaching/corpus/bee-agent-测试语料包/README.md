# Bee Agent 测试语料包（隐私已脱敏）

用于测试自建 Agent：输入是转写，对照输出是 Bee 当时生成的摘要 / 事实 / 待办 / 成长洞察。

**请注意：摘要和洞察是 Bee 的原始产出，只做了脱敏，不是人工标注的标准答案，也不能当作官方提示词。**

时区：Asia/Shanghai（北京时间）。日期为原始发生日期，保留未改。

## 目录结构

```
README.md
manifest.json
classroom/sample-01/   比较教育学（双语）：国别教育比较的四个维度（2026-11-12）
classroom/sample-02/   课程与教学论：后现代课程理论与多尔四R（2026-11-13 前半段）
classroom/sample-03/   课程与教学论：永恒主义教育思想（2026-11-13 后半段）
classroom/sample-04/   讲座：AI 评估的新科学前沿（2026-11-12 晚）
project/sample-01/     留学咨询：AI＋教育 / 产品与管理方向（2026-11-12）
project/sample-02/     项目讨论：自进化 AI 教学产品的机制与分工（2026-11-11）
grow/insight-01~07/    7 条成长洞察（学业、产品伦理、第二大脑、职业方向）
grow/daily-01/         每日回顾 2026-11-12
grow/daily-02/         每日回顾 2026-11-13
shared/                用户确认过的「课堂或讲座」纪要规则
```

每个会话目录通常包含：

- `transcript.txt`：转写（测试输入）
- `summary.md`：Bee 原摘要的脱敏版（对照输出）
- `facts.json` / `todos.json`：若该段在当前库中已无自动抽取记录，则为空数组
- `meta.json`：样本元数据、日期、脱敏说明

成长类目录是 `insight.json` 或 `daily.md`，一般不附完整转写；相关会话见 `related_samples`。

## 建议测试方式

1. **会话摘要**  
   只把 `transcript.txt` 送给 Agent，让它输出课堂笔记或会议纪要。再与 `summary.md` 对照结构、要点覆盖和风格，而不是逐句求同。

2. **规则是否生效**  
   先把 `shared/用户规则-课堂或讲座.md` 作为已确认记忆/系统约束输入，再摘要 `classroom/sample-02` 和 `sample-03`。可对照：sample-02 已明显改成「要记住的 / 本节课回答的问题 / 复习自测」；sample-03 是同一节课的后半段，仍偏默认模板并追加了自测。sample-01、sample-04 接近默认模板，可作对照组。

3. **事实与待办抽取**  
   多数样本的 `facts.json`、`todos.json` 为空（这些会话的自动事实后来未保留在库中）。可让 Agent 自行抽取，再与摘要里的 Action items、复习自测对照。`project/sample-02` 提供了 1 条相关已有事实，可测「已有记忆去重」。

4. **成长 / Grow**  
   用当天课堂+项目摘要（或 `daily.md`）作为输入，让 Agent 写 1–3 条跨会话洞察，再与 `grow/insight-*.json` 对照主题是否站得住，不必追求措辞一致。

5. **会话切分**  
   `classroom-02` 与 `classroom-03` 是同一节《课程与教学论》被静音规则拆开的两段，可用来测合并摘要或跨段记忆。

## 转写说明

- 说话人标签统一为 `Unknown`，与 Bee 原数据一致（本账号未做说话人分离）。不要把别人的话写成「用户说的」。
- 时间戳为当天 `HH:MM:SS`（Asia/Shanghai）。
- `classroom-01` 已删除课后私人闲聊；其他样本本身即以课堂、讲座或项目讨论为主。

## 脱敏说明

已替换或删除：

- 用户真名、证件名
- 老师、同学、合作者等真实姓名（如咨询老师、同学甲/乙、合作者A）
- 本校、本院，以及咨询中出现的目标院校全称和简称（改为 目标高校A、B、C…，对照表见 `project/sample-01/meta.json`）
- 精确绩点与百分制分数
- 邮箱、手机、社交账号、证件号、Bee 用户/会话编号
- 精确地址、教室门牌、经纬度
- 民族、生源地等身份信息
- 经期、亲密关系等私人生活内容（不纳入本包）
- 邮件原文、日历明细、照片

保留：多尔四R、泰勒原理、永恒主义、Goodhart 定律、表现/能力区分、比较教育四维框架、NEP 2020、Aristotle / OpenTutor 等公开学术与产品内容。这正是要测的知识。

公开讲座讲者、图灵、赫钦斯等历史或公开学术人名未改。

## 不包含什么

- 日常闲聊、私人生活、感情或家庭对话
- 未脱敏的原始 JSON、邮件、位置轨迹
- Bee 官方提示词（本包只有行为层的输入/输出样本）
