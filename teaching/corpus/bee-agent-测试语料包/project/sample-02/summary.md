# 项目讨论：自进化 AI 教学产品的机制与分工

> 原短标题（已脱敏）：AI教学项目自进化方案分工讨论

# Summary

用户与两位队友开会筹备一项比赛/项目，核心是做一个结合硬件采集与 AI 教学的“自进化”学习产品。团队讨论了小米手环、摄像头和语音采集模块的可用性，明确硬件可能需要自行采购，并决定先按缺少硬件支持的情况设计，现场再确认和调试。

产品方面，用户提出 AI 应根据学习者掌握情况动态调整讲解难度：已掌握的内容少重复，尚未掌握或更高阶的内容主动深入讲解。团队计划参考已有产品逆向得到的教学流程，包括单节课讲授、课后保存、记录与摘要，并继续研究“自进化/半进化”机制及其技术实现。

# Atmosphere

会议节奏高效、务实且友好。大家在技术可行性上仍有不确定之处，但愿意边学习、边调研、边推进，并对线下比赛时的协作保持积极预期。

# Key Take aways

- 硬件方面优先考虑小米手环，摄像头和语音采集模块无法保证由他方提供，需要自行采购或准备替代方案。
- 小米手环的开发者模式和可开发性需要进一步现场验证；有人认为小米手环 10 陶瓷版或许可用于调试。
- AI 教学机制的关键设想是基于学习过程持续记录学习者“会什么、不会什么”，实现分层、个性化讲解。
- 团队将参考一个已有网站逆向出的教学逻辑和流程图，重点借鉴课程讲解、课后记录和摘要的结构。
- 对“全闭环自进化”与“半闭环/半进化”尚未形成统一定义，后续需要结合论文和实际实现难度选择方案。
- 目前团队三人，预留了一个成员名额；后续可根据缺少的能力再邀请第四位成员。
- 比赛前的准备以阅读论文、研究 Aristotle 等产品、查看同类成品并在群内共享资料为主。

# Division of Work

- 用户负责教学机制设计，继续阅读相关论文，并研究 Aristotle 的教学模式可以如何改进和迁移。
- 一位队友主要负责课堂采集相关工作，先推进录音采集；若时间允许，再继续尝试摄像头等采集功能。
- 教学机制实现、Agent 设计与模型训练相关工作由团队协同推进，技术细节主要需要两位更熟悉技术的队友补充。
- 用户也愿意承担展板等视觉呈现工作，发挥审美与设计能力。

# Action Items

- 确认小米手环的开发者模式、版本兼容性及实际调试方案。
- 调查摄像头、录音模块等硬件的采购与替代选择。
- 阅读并讨论群内分享的教学流程图，决定是否将其作为产品初版框架。
- 用户继续梳理自适应教学/半进化机制相关论文，并研究 Aristotle 的可借鉴设计。
- 三人持续收集同类产品、论文和案例，发现有价值的信息及时发到群内共享。
- 线下比赛前再根据实际缺口决定是否招募第四位队员。
