### 各版本保留了什麼

- **黄紫 React 版**：页面、配色、布局、记忆/待办/事实/成长/笔记全部保留；只加了 3 个入口和 1 个第二大脑页。
- **Bee 第二大脑**：`second-brain/` 是原复刻代码，不改；它的产出通过 `bridge/bee_sync.py` 进教学库，教学 Agent 的讲解/裁决提示词会带上已确认事实与洞察。
- **MetaMind-打包**：5001 教学服务原样运行。旧版记忆站（5002）已从导航和启动脚本移除，文件夹保留但不再启动。
- **OpenTutor**：作为自进化底座运行，提供学习者状态、评价、反思、策略版本、调用追踪；本次补了前端一直缺的 `/api/workspace/*` 和共享工作空间存储。

## 六、常见问题

**Q：为什么“教学 Agent”不是 OpenTutor 那个课堂页？**
队员写的 `ClassroomPage` 调用 `/api/classroom/*`，但交接包里没有这套后端接口（OpenTutor 源码里也没有）。
为了不给你一个卡死的入口，导航先指向真正能用的 5001 教学页；实验页仍在 `/classroom` 路由下，等接口补齐再接。

**Q：`/grow` 里的分数为什么是 0/2？**
这是交接包里的真实记录：两次运行的理解/应用都是 0 分，迁移未测量。没有替你改成好看的数字。

**Q：没有 API Key 能跑吗？**
能打开全部页面和已有数据；新的拍照/录音分析、问答生成需要 Key。
OpenTutor 已接到 `teaching/api_key.txt` 里的 SiliconFlow key（`deepseek-ai/DeepSeek-V4-Flash`）。
不要把 `api_key.txt`、`metamind.db`、`uploads/` 发群。

**Q：换电脑怎么装？**
OpenTutor 需要 Python 3.12（本机由 uv 安装，在 `.venv-ot312`）；教学服务需要 Flask；前端需要 Node 22/24。
`node_modules` 已随包，但 Windows 专用的 rollup 二进制若丢失，执行：
`npm install --no-save @rollup/rollup-win32-x64-msvc @esbuild/win32-x64`。

| P1 项 | 实现方式 | 真实边界 |

| 认知对抗沙盒（最小版） | 同错因换一批新题复测，答对才算稳定 | 不是完整对抗沙盒，样本小，不能单独证明“假性掌握” |
