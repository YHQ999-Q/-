# MetaMind 硬件联调清单（板子到手照着做）

## 0. 先确认电脑和服务器

- 电脑和手表连**同一个 2.4G WiFi**。
- 电脑 IPv4 用 `ipconfig` 查；当前是 **192.168.1.197**（会变，以 ipconfig 为准）。
- 双击 `MetaMind-hackathon\启动全部.bat`，浏览器打开：
  `http://127.0.0.1:5001/teach` 能看到页面 = 教学服务 OK。
- 浏览器打开 `http://127.0.0.1:5000/health` 返回 `"asr":true,"ocr":true` = 本机感知 OK。

## 3. 接线核对

### 摄像头（OV2640 / OV5640）
按 `接线表.txt`。最容易错的三处：
- 排线没插到底 / 插反
- SCCB 的 SDA(40) / SCL(39) 接反
- 摄像头供电接成 5V（必须 3.3V）

### 麦克风 INMP441
| INMP441 | ESP32-S3 |
|---|---|
| VDD | 3.3V |
| GND | GND（必须共地） |
| L/R | GND（左声道） |
| SCK/BCLK | GPIO20 |
| WS/LRCK | GPIO21 |
| SD/DIN | GPIO19 |

### 按键 / 震动
| 功能 | GPIO |
|---|---|
| KEY_PHOTO（拍板书+录音） | 41 |
| KEY_RECORD（只录音） | 42 |
| VIB（震动马达） | 43 |

按键是**低电平触发**（按下接 GND），代码里开了上拉。

## 6. 常见问题

| 现象 | 先查 |
|---|---|
| 摄像头初始化失败 0x105 | 排线/供电/引脚；代码已自动从 VGA 退 QVGA |
| 麦克风全 0 或噪声 | L/R 是否接 GND、三根线是否接对、是否共地 |
| WiFi 一直重连 | 是否 2.4G、SSID 是否中文、密码是否 WPA2 |
| 上传失败 `ESP_ERR_HTTP_CONNECT` | `SERVER_BASE` IP 是否当前电脑 IP、防火墙是否放行 5001 |
| 网页没反应，但串口显示上传成功 | 看 5001 窗口日志；确认打开的是 5001 不是 5000 |
| 板子无限重启 | 换带电源的 USB 口；`idf.py erase-flash` 后重烧 |

## 7. 降级开关（现场救命）

`main/board_config.h`：
```c
#define ENABLE_CAMERA 0   // 摄像头坏了先关
#define ENABLE_MIC    0   // 麦克风坏了先关
```
`main/app_config.h`：
```c
#define ENABLE_WIFI 0     // 纯离线调试
```
改完必须重新 `一键编译.bat` + 烧录。

## 8. OLED 说明

当前固件**没有驱动 0.96 寸屏**（模板里没有屏的引脚定义）。
后端已经留好一行状态接口：

```
GET /api/teach/result/esp32-s3-A1B2
→ {"line":"[OK] CONCEPT"}
```

等你确认屏的型号（SSD1306 / SH1106）和 I2C 引脚后，再加显示驱动即可，
状态行只发英文，避免中文字库问题。
