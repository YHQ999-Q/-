# MetaMind 黄紫配色

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 原有主黄 | `#FFD900` | 欢迎区、关键操作、导航选中 |
| 品牌蓝紫 | `#5A00FF` | 主紫、图形、对话入口、强调 |
| 深紫 | `#32105E` | 桌面侧栏、正文与深色按钮 |
| 淡紫 | `#EEE7FF` | 次级卡片、选中标签、内容背景 |
| 近白淡紫 | `#F7F4FF` | 页面底色 |

## 为什么是这款紫

主黄从当前实际 CSS 读取，RGB 为 `(255, 217, 0)`，HSL 色相约 `51.06°`。它是稍偏橙的明黄色。

传统 RYB 艺术色轮中，黄色与紫罗兰色互补。RYB 艺术色轮与显示器用的 RGB 色相环不是同一套模型，不能宣称某一个紫色色号是当前黄色唯一的“光谱标准对应值”。

这版使用传统艺术色轮的黄紫关系，并选偏蓝紫的 `#5A00FF` 作为品牌紫。参考简化的 RYB 色相分段映射：红 0°→RGB/HSL 0°、橙 60°→30°、黄 120°→60°、绿 180°→120°、蓝 240°→240°、紫 300°→270°，在相邻锚点间线性插值，再在 RYB 环旋转 180°，得到的紫色接近 `#5A00FF`。这是本项目的设计映射，不是统一标准或 Pantone 指定值。

如果直接在 RGB/HSL 环将 `#FFD900` 的色相旋转 180°，得到的会是偏蓝的 `#0026FF`，不是本次选用的黄紫艺术配色。

按 sRGB 相对亮度公式计算，`#FFD900` 与 `#5A00FF` 的对比度约 `5.27:1`。该数字仅适用于这两个实色直接相邻的文字/背景组合，不代表整站已经完成无障碍认证。
